# Public Release Boundary

This branch is the publication-oriented SafeOCR source surface.

The scientific record remains in code, frozen protocols, machine-readable evidence artifacts, reproducibility documentation, and the manuscript. Internal editorial strategy, journal-targeting notes, draft cover letters, reviewer-risk notes, and AI self-scoring/review summaries are intentionally excluded from the current tree because they are not scientific evidence and should not be presented to readers as such.

This cleanup does not rewrite Git history and does not alter any frozen result, protocol, source code used to produce an evidence artifact, or claim-boundary record.

## Included as scientific/reproducibility material

- source code and tests;
- frozen evaluation artifacts;
- frozen protocols plus post-outcome addenda;
- manuscript and arXiv source;
- claims ledger;
- novelty map;
- literature/search audit;
- reproducibility statement;
- reporting checklist.

## Excluded from the publication surface

- journal-selection strategy;
- draft cover letters;
- internal reviewer-risk planning;
- AI-generated quality scores or self-review evidence;
- unresolved submission-form metadata.

Submission-specific materials can be maintained outside the public release tree and regenerated from the verified manuscript when needed.
