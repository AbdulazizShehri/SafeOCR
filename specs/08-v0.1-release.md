# F8 — v0.1 Release

Status: QUALIFIED RELEASE CANDIDATE — MERGE PENDING
Depends on: F7 Static Evidence Report (`f39540e1401d4347dd08bea77c35077933cbd484`)

## Objective

Freeze SafeOCR v0.1 as a reproducible, research-only healthcare OCR verification release with complete package metadata, license/notices, CI, release evidence, and a canonical Git history ready for normal merge and publication.

## Release contract

1. Version is exactly `0.1.0`.
2. Project license is Apache-2.0; third-party licenses remain separately attributed.
3. Public documentation must state that SafeOCR is research software, not a medical device, and must not be used for diagnosis or treatment.
4. Package build must not require paid services, cloud inference, real PHI, or network access at runtime.
5. Default CI must run on Python 3.11 and 3.12 and cover pytest, Ruff, Pyright strict, and package build.
6. Runtime-heavy OCR/FHIR smoke tests remain explicit opt-in gates with canonical local evidence already frozen.
7. Canonical F4, F5, F6, and F7 evidence artifacts must be present and hashable.
8. Release metadata must preserve declared F6 limitations; no performance claim may exceed the frozen evidence.
9. The release candidate must pass Jev, Alibaba Open Code Review delegated rules, Graft, tests, lint, types, dependency check, and package build.
10. Final integration into `main` uses a normal merge commit only. No squash, rebase, force-push, or history rewriting.
11. Release tag `v0.1.0` may be created only after the exact merged `main` head is qualified.
12. Remote publication must preserve the canonical local history.
